# DATA 4000 Python with AI - Assignment 3

Ten Python exercises practicing loops, lists, and dictionaries with business examples.

Files

checkout.py - Asks for item prices until 0 is entered, then prints the total, average, and number of items.

survey.py - Counts customer drink choices with a dictionary and prints each product's market share.

expenses.py - Uses nested loops to total each expense category and the grand total.

commissions.py - Calculates a 10% commission for each employee and prints a ranked leaderboard.

portfolio.py - Calculates the total value of a stock portfolio and simulates a week of random price changes.

loan_simulator.py - Simulates monthly loan payments to find how many months it takes to pay off the loan.

supply_chain.py - Adds up the stock of each product across all warehouses.

loyalty_tiers.py - Sorts customers into Bronze, Silver, and Gold tiers and counts each tier.

growth_projection.py - Projects revenue over 10 years using a yearly growth rate.

pitch_chart.py - Draws an ASCII bar chart of projected revenue using # symbols.
